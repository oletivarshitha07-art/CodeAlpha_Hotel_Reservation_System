The Hotel Reservation System is a Java-based application designed to simplify hotel room management and reservations.
The system allows users to search for available rooms, select room categories, make reservations, manage bookings, and simulate payments.

Objective
The objective of this project is to demonstrate Java programming and Object-Oriented Programming concepts by developing a practical hotel reservation and room management system.
